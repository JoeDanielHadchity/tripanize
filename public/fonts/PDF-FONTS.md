The PDF uses static weight instances of the existing Inter (400 and 600)
and Fraunces (600) Latin web fonts. These TTF files were generated with
fontTools.varLib.instancer from the adjacent variable WOFF2 files, with
the weight axis pinned and the WOFF2 flavor removed. Their original SIL
Open Font Licenses are in Inter-LICENSE.txt and Fraunces-LICENSE.txt.

DejaVu Sans remains the fallback for characters outside the Latin font
subsets. All fonts are embedded and subset in each exported PDF.
